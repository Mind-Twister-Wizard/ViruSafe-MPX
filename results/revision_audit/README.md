# Professor-review revision audit tables

These CSV files were generated from saved ViruSafe-MPX v1.1 outputs to address methodological clarification requests in the professor-reviewed IEEE ESCI manuscript.

They are **audit/reporting artifacts**, not a new training run. The executable code state cited by the paper is commit **06ca6f6**.

The folder covers grouped fold accounting, reliability-head parameters, calibration/NLL, pooled metrics, selective prediction, conformal calibration/coverage/set sizes, OOD candidate selection and held-out results, MSID duplicate/per-class audits, cluster-aware statistical inference, robustness and Grad-CAM variability.

Interpret these files together with ../../docs/MANUSCRIPT_REVISION_AUDIT.md.

# Datasets and licensing

The repository **does not redistribute dataset image files**. The pipeline downloads them from their original/public hosting locations at execution time.

| Dataset | Purpose | Identifier |
|---|---|---|
| MSLD v2.0 | 6-class model development + grouped OOF testing | Kaggle: `joydippaul/mpox-skin-lesion-dataset-version-20-msld-v20` |
| DermNet | OOD method selection + held-out-category testing | Kaggle: `shubhamgoel27/dermnet` |
| MSID | External validation only | Kaggle: `sujaykapadnis/monkeypox-skin-images-dataset-msid` |

Please verify the current source licenses and image-reproduction permissions before redistributing photographs or derived overlays. The code and aggregate numerical outputs in this repository are distinct from the source-image licenses.

For publication, prefer aggregate plots/tables unless you have confirmed permission to reproduce lesion photographs.
